A Beginner-Simple full-stack Resume Builder web app with a React frontend(! inspired ui !) and a Node.js/Express + MongoDB backend.( WT project )

# disclaimer
* all images of people used in the templates are intended for use as sample/demo images sourced from the internet and are included for illustrative purposes only. They do not represent real users of this project.

Note : To Add other templates u would need to manually customize the already existing templates to fit ur need .

HOW TO RUN :

1.npm start in backend folder

2.npm start in frontend folder

3.make sure to reconfigure port numbers incase of errors !

4.note that it may fail to run some packages incase there is version mismatch or package non availability in your current version of node ,etc.

5.Try npm install in that case , if it still fails you will have manually install the correct versions.

6.make sure to edit the .env file with your keys :
>JWT : a random string backend uses to sign and verify tokens.<br>
>MongoURI : mongodb://localhost:27017/db1 , change to ur mongo db setup .<br>
The setup I used is availaible as mongosetup.png.

@note that the frontend wrt resume creating ui was inspired and built via a yt tutorial!
